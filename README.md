# 🏙️ Public Issue Reporting System

## 📌 Project Description

This project is a web-based application that allows users to report local issues (such as road damage, garbage, water problems, etc.) directly to the concerned authorities. Users can submit complaints by filling out a form with details like problem description, location, and image upload.

Once submitted, the reported issues are displayed as cards on the landing page, making it easy to view and track ongoing problems in a specific area.

---

## 🚀 Features

* 📝 User-friendly complaint submission form
* 📍 Location-based issue reporting
* 🖼️ Image upload for better clarity of problems
* 🗂️ Dynamic issue cards displayed on homepage
* 💾 Data stored using Local Storage
* 📱 Responsive design for different devices

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage

---

## 💡 Use Case

This project helps bridge the gap between citizens and government authorities by providing a simple platform to report and visualize local problems efficiently.
